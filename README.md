# JetQueries

Fast, elegant, extension-based database IDE for SQL Server, Oracle, PostgreSQL, SQLite and Redis.
Built with .NET 10 and Avalonia.

> Status: Phase 0 (foundation). Not usable yet.

- Product analysis (Turkish): [docs/ANALIZ.md](docs/ANALIZ.md)
- Contributor / AI agent guide: [CLAUDE.md](CLAUDE.md)

## Build

```
dotnet build JetQueries.slnx
dotnet run --project src/JetQueries.Desktop
```
